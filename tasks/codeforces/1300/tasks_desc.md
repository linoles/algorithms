# Краткое описание и суть моих решений задач сложности 1300

## 230B - Т-простые числа

Решетом Эратосфена находим все простые числа до 10^6. Затем пытаемся извлечь корень из каждого x. Если извлечённый корень простой, то x - Т-простое. O(n)

## 181B - Сколько троек

Перебираем B, для каждого перебираем A. Для них высчитываем C и проверяем существование такого C в данном массиве за O(log n). O(n² \* log n)

## 251A - Точки на прямой

Перебираем правый указатель, двигая левый, пока расстояние не станет больше d. O(n)

## 1418B - Отрицательные префиксы

Сортируем разблокированные числа и вставляем их обратно. O(n \* log n)

## 152B - Шаги

Для каждого вектора считаем сделанное кол-во шагов по каждой координате. O(n)

## 192A - Модные числа

Перебираем первое k до √n, а второе m находим по формуле бинарным поиском. O(√n \* log √n)

## 96B - Счастливые числа (упрощенная версия)

Собираем все очень счастливые числа длиной от 2 до 10, затем бинарным поиском среди них ищем первое число не меньше n. O(1)

## 1703F - Очередная задача про пары, удовлетворяющие неравенству [Не решено]

Примитивное решение O(n²), получает TLE. O(n²)

## 1612C - Бан в чате

Симулируем префиксные суммы массива сообщений, где ai - означает, сколько эмодзи будет в сообщении номер i. Среди них бинарным поиском ищем первое ai >= x. O(log n)

## \*1807E - Интервью

С каждым запросом сужаем диапазон в два раза. O(n)

## 2146C - Неправильный бинарный поиск

Проходимся по строке, фиксируем единицы на своих местах, а каждый макс. непрерывный блок нулей заполняем убывающими числами. O(n)

## 1076C - Мемная задача

a, b - корни x² - d * x + d = 0. Поэтому достаточно просто решить это уравнение. O(1)

## 2170C - Частное и остаток

Сортируем q по убыванию, r по возрастанию. Затем жадным алгоритмом и указателем на rj ищем кол-во подходящих пар по полученной формуле. O(n * log n)
