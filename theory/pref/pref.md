# Префиксные суммы

Массив b префиксных сумм массива a имеет длину на 1 больше длины массива a и следующий вид:

$$
b[0] = 0, b[1] = a[0], b[2] = a[0] + a[1], b[n] = a[0] + a[1] + ... + a[n - 2] + a[n - 1] ...
$$

$$
т.е., b[i] = \displaystyle\sum\_{j=0}^{i-1} a_j
$$

Например:

| Массив | 0   | 1   | 2   | 3   | 4   | 5   |
| ------ | --- | --- | --- | --- | --- | --- |
| a      | 5   | 3   | -2  | 1   | 4   | -   |
| b      | 0   | 5   | 8   | 6   | 7   | 11  |

## Построение (Реализация)

$
b[i] = \displaystyle\sum_{j=0}^{i-1} a_j \\
b[i + 1] = \displaystyle\sum_{j=0}^{i-1} a_j + a[i] \\
b[i + 1] = b[i] + a[i]
$

Через эту формулу можно реализовать построение за O(n):

```C++
vector<int> b(a.size() + 1, 0);
for (int i = 0; i < a.size(); i++)
  b[i + 1] = b[i] + a[i];
```

## Сумма на отрезке

Для вычисления по префиксным суммам сумму элементов массива на отрезке [l, r] за O(1), используется следующая формула:

$$
sum(l, r) = pref[r + 1] - pref[l] \text{ при } l, r ∈ [0, n - 1] \text{ (В 0-indexed)}
$$

$$
sum(l, r) = pref[r] - pref[l - 1] \text{ при } l, r ∈ [1, n] \text{ (В 1-indexed)}
$$

## Многомерные префиксные суммы

Многомерные префиксные суммы вычисляются так же, как и одномерные. Например, вот вычисление массива b преф. сумм двумерного массива a:

$$
b[i][j] = \displaystyle\sum_{x=0}^{x<i}\sum_{y=0}^{y<j} a_{x,y} = [0, i) × [0, j)
$$

### Построение преф. сумм двумерного массива a

Для построения есть два способа:

1. Построение через предварительный массив из n одномерных префиксных сумм каждого ряда, а затем построение итогового массива преф. сумм по колонкам;
2. Построение сразу по следующей формуле (Здесь мы учитываем левое и верхнее, вычитаем левое верхнее, т.к. оно учитывается дважды и добавляем новое текущее):
   $$
   b_{i+1,j+1} = b_{i,j+1} \text{(сверху)} + b_{i+1,j} \text{(слева)} - b_{i,j} \text{(слева сверху)} + a_{i,j} \text{(новое число)}
   $$

Реализация второго способа (наиболее приятный, компактный и быстрый):

```C++
int n = a.size(), m = a[0].size();
vector<vector<int>> b(n + 1, vector<int>(m + 1, 0));
for (int i = 0; i < n; i++)
  for (int j = 0; j < n; j++)
    b[i + 1][j + 1] = b[i][j + 1] + b[i + 1][j] - b[i][j] + a[i][j];
```

### Счёт сумм на прямоугольнике

На прямоугольнике сумма элементов в прямоугольнике $[lx, rx) × [ly, ry)$ (Считая координатами x - номер строки, y - колонки) считается по следующей формуле:

$$
sum(lx, rx, ly, ry) = b_{rx,ry} \text{(правый низ)} - b_{lx,ry} \text{(правый верх)} - b_{rx,ly} \text{(левый низ)} + b_{lx,ly} \text{(левый верх)}
$$

Объяснение:

1. Мы берём $b_{rx,ry}$, считая сумму прямоугольника $[0, 0] × (rx, ry)$;
2. Теперь мы вычитаем ту часть, что выше прямоугольника: $b_{rx,ly}$
3. Теперь мы вычитаем ту часть, что левее прямоугольника: $b_{rx,ly}$
4. Получается, что мы два раза вычли часть $[0, 0] × (lx, ly)$ (пересечение прошлых двух прямоугольников), добавляем её через $b_{lx,ly}$

## Разностный массив

Допустим, a - какой-то массив, b - его префиксные суммы, тогда разностный массив массива b будет являться массивом a. Разностный массив имеет длину на 1 меньше исходного и строится по следующему правилу:

$$
a[i] = b[i + 1] - b[i]
$$

Переход к массиву префиксных сумм b - это дискретное интегрирование, то есть $b = \int a$ и тогда переход к разностному массиву - дискретное дифференцирование: $a = b'$. И получается:

$$
a = b' = (\int a)' = a \\
b = \int a = \int (b') = b
$$

### Прибавление константы на полуинтервале

Для прибавления ко всем элементам одномерного массива на полуинтервале $[l, r)$ константы, можно изменять лишь две границы, а затем восстановить исходный массив по разностному:

$$
a_{l} = a_{l} + d, \\
a_{r} = a_{r} - d
$$

### Прибавление на отрезке арифметической прогрессии

Помимо прибавления константы, может понадобится быстрое прибавление арифметической прогрессии на полуинтервале $[l, r)$, тогда к каждому $a_i$ в промежутке с $l$ по $r - 1$ включительно должно прибавиться $(i - l + 1)d$ (при одинаковой индексации $i, l$). К последнему, получается, прибавится $(r - l)d$.

В таком случае разностный массив a изменится следующим образом: к первым (с номера $l$) $(r - l)$ числам прибавится d, а к следующему прибавится $-(r - l)d$. И для этого потребуется O(n) на каждый запрос, однако можно построить разностный массив o разностного массива a изначально, и тогда он будет подвергаться каждый раз трём следующим изменениям:

$$
o_{l-1} = o_{l-1} + d, \\
o_{r-2} = o_{r-2} - (r - l + 1)d, \\
o_{r-1} = o_{r-1} + (r - l)d
$$

### Разностный двумерный массив

При двумерном массиве b, разностный массив a заполняется по нему следующим образом:

$$
a_{i,j} = b_{i+1,j+1} - b_{i,j+1} - b_{i+1,j} + b_{i,j}
$$

### Прибавление константы на прямоугольнике

В двумерном массиве также возможно прибавлять константу на прямоугольник с заданными координатами $[lx, rx) × [ly, ry)$. Для этого в двумерном разностном массиве проводим следующие операции:

$$
a_{lx,ly} = a_{lx,ly} + d, \\
a_{lx,ry} = a_{lx,ry} - d,
a_{rx,ly} = a_{rx,ly} - d, \\
a_{rx,ry} = a_{rx,ry} + d
$$

Здесь почти такой же принцип, как со счётом суммы элементов на прямоугольнике
