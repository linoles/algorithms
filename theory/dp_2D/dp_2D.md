# Двумерное динамическое программирование (дп)

## Нахождение числа сочетаний

Допустим, есть n предметов. Задача в том, чтобы найти кол-во способов выбрать из этих n предметов k штук, если порядок выбора неважен. Для этого существует биномиальный коэффициент:

$$
\binom{n}{k} = C_n^k = \frac{n!}{k!(n-k)!}
$$

Следующая наивная реализация:

```C++
ll fact(int n)
{
  ll res = 1;
  for (int i = 0; i <= n; i++)
    res *= i;
  return res;
}

ll C(int n, int k)
{
  return fact(n) / fact(k) / fact(n - k);
}
```

работает, однако при n/k > 20 будет выход за границы в функции факториала ($ 21! = 51090942171709440000 $), а сам биномиальный коэффициент при этом может и не выходить за границы.

Но можно выразить $\binom{n}{k} = C_n^k$ рекурсивной формулой:

$$
\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k} =
$$

$$
C_n^k = C_{n-1}^{k-1} + C_{n-1}^k\text{, при } n > k > 0
$$

```C++
// Оптимизированная версия рекурсивной функции с помощью мемоизации
map<pair<int, int>, ll> memo; // Значения, которые уже рассчитанны
ll C(int n, int k)
{
  if (k == 0 || k == n)
    return 1;
  pair<int, int> p = make_pair(n, k);
  if (memo.count(p)) // Смотрим, считали ли мы уже такой бином
    return memo[p];
  return memo[p] = C(n-1, k-1) + C(n-1, k); // Если нет, заполняем его
}

// Циклическая версия через дп
int C(int n, int k)
{
  int dp[n+1][n+1];
  for(int i = 0; i <= n; i++)
  {
    // Базовый случай
    dp[i][0] = 1;
    dp[i][i] = 1;
    for(int j = 1; j < i; j++)
      dp[i][j] = dp[i-1][j-1] + dp[i-1][j];
  }
  return dp[n][k];
}
```

## Маршруты на плоскости

> Дана прямоугольная доска размером n×m (n строк и m столбцов). В левом верхнем углу этой доски находится шахматный король, которого необходимо переместить в правый нижний угол.

### Количество маршрутов

Необходимо найти кол-во возможных маршрутов короля до точки назначения. Пусть $ dp\_{a,b} $ &ndash; кол-во маршрутов, ведущих к $(a, b)$ из левого верхнего угла $(0, 0)$. В точку $(a, b)$ можно попасть через левую клетку $(a, b-1)$ и верхнюю клетку $(a-1, b)$. Рекуррентная формула:

$$
dp_{a,b} = dp_{a-1,b} + dp_{a,b-1} \text{, при } a, b > 0
$$

При $a = 0$ или $b = 0$, в точку можно попасть только одним способом, поэтому $dp_{0,b} = 1, dp_{a,0} = 1$. Заполнение массива $dp$:

```C++
vector<vector<ll>> dp(n, vector<ll>(m, 1));
for (int i = 1; i < n; i++)
  for (int j = 1; j < m; j++)
    dp[i][j] = dp[i-1][j] + dp[i][j-1];
// Ответ: dp[n-1][m-1]
```

Также в коде нам требуется для каждого значения знать только предыдущие столбец и строчку, поэтому код можно оптимизировать по памяти:

```C++
vector<ll> dp(m, 1);
for (int i = 1; i < n; i++)
  for (int j = 1; j < m; j++)
    dp[j] = dp[j-1] + dp[j];
// Ответ: dp[m-1]
```

> Этот код интересен тем, что рекуррентная формула $dp_{j} = dp_{j-1} + dp_{j}$ строится так, потому что в $dp_{j-1}$ значение уже поменялось, значит хранится левая клетка, а в $dp_{j}$ значение осталось с предыдущей строки: получается, берём значение сверху

### Количество маршрутов с препятствиями

Пусть даны клетки, на которые король ступать не может. Эти клетки заданы массивом $Map[n][m]$. Пусть в нём для каждой клетки $(a, b)$ значение $Map_{a,b}$ равно $1$, если на клетку можно ступать, иначе $0$. Реализация заполнения таблицы $dp[n][m]$:

```C++
vector<vector<ll>> dp(n, vector<ll>(m, 1));
dp[0][0] = Map[0][0];
for (int j = 1; j < m; j++) // Заполнение первой строки
  dp[0][j] = min(dp[0][j-1], (ll)Map[0][j]); // Если встретится 0, дальше все будут нули
for (int i = 1; i < n; i++)
{
  dp[i][0] = min(dp[i-1][0], (ll)Map[i][0]); // Если встретится 0, ниже все будут нули
  for (int j = 1; j < m; j++)
    dp[i][j] = Map[i][j] ? (dp[i][j-1] + dp[i-1][j]) : 0; // Если нельзя попасть, путей 0
}
// Ответ: dp[n-1][m-1]
```

И также оптимизированный по памяти вариант с линейным дп, где заместо предварительного ввода всей таблицы $Map[n][m]$, сохраняется только последнее введённое число: (При этом $n, m$ введены заранее, как и объявлен $int \ Map$, а также в комментариях я указал, какое значение $Map$ соответствует каждому вводу)

```C++
vector<ll> dp(m, 1);
scanf("%lld", &dp[0]); // dp[0] = Map[0][0]
for (int j = 1; j < m; j++) // Заполнение первой строчки
{
  scanf("%d", &Map); // Map[0][j]
  dp[j] = min(dp[j-1], (ll)Map);
}
for (int i = 1; i < n; i++)
{
  scanf("%d", &Map); // Map[i][0]
  dp[0] = min(dp[0], (ll)Map); // Также учитываем то, что мог встретиться 0
  for (int j = 1; j < m; j++)
  {
    scanf("%d", &Map); // Map[i][j]
    dp[j] = Map ? (dp[j-1] + dp[j]) : 0;
  }
}
// O(m) по памяти, O(nm) по времени
// Ответ: dp[m-1]
```

### Путь максимальной стоимости

Пусть для каждой клетки $(a, b)$ есть стоимость $P_{a,b}$ данной клетки. Задача в том, чтобы найти максимальную возможную сумму на пути к правому нижнему углу. Пусть $dp_{a,b}$ &ndash; макс. сумма, которую можно получить, дойдя до клетки $(a, b)$. При этом:

$$
dp_{0,0} = P_{0,0} \\
dp_{0,b} = dp_{0,b-1} + P_{0,b} \\
dp_{a,0} = dp_{a-1,0} + P_{a,0}
$$

А сама рекуррентная формула (стоимость пребывания на $(a, b)$ и максимальная из двух стоимостей: левой и верхней клетки):

$$
dp_{a,b} = P_{a,b} + max(dp_{a-1,b}, dp_{a,b-1})\text{, где } a, b > 0
$$

Реализация заполнения $dp[n][m]$ без оптимизаций по памяти:

```C++
vector<vector<ll>> dp(n, vector<ll>(m));
dp[0][0] = P[0][0];
for (int j = 1; j < m; j++) // Заполнение первой строки
  dp[0][j] = P[0][j] + dp[0][j-1];
for (int i = 1; i < n; i++)
{
  dp[i][0] = P[i][0] + dp[i-1][0]; // Первый столбец
  for (int j = 1; j < m; j++)
    dp[i][j] = P[i][j] + max(dp[i-1][j], dp[i][j-1]);
}
// Ответ: dp[n-1][m-1]
```

Оптимизированный вариант:

```C++
vector<ll> dp(m);
scanf("%d", &dp[0]); // dp[0] = P[0][0]
for (int j = 1; j < m; j++) // Первая строка
{
  scanf("%d", &P); // P[0][j]
  dp[j] = P + dp[j-1];
}
for (int i = 1; i < n; i++)
{
  scanf("%d", &P); // P[i][0]
  dp[0] += P;
  for (int j = 1; j < m; j++)
  {
    scanf("%d", &P); // P[i][j]
    dp[j] = P + max(dp[j], dp[j-1]);
  }
}
// Ответ: dp[m-1]
```

Также можно изменить код так, чтобы он не только возвращал стоимость пути, но и сам путь. Для этого можно просто с конца восстановить ответ, сравнивая левую и верхнюю стоимости:

```C++
int i = n-1, j = m-1;
string ans;
while (i > 0 && j > 0)
{
  if (dp[i][j-1] >= dp[i-1][j]) {
    ans = 'R' + ans; j--;
  }
  else {
    ans = 'B' + ans; i--;
  }
}
while (i > 0) {
  ans = 'B' + ans; i--;
}
while (j > 0) {
  ans = 'R' + ans; j--;
}
// (вариант работает при полном заполнении dp[n][m], а не оптимизированном dp[m])
// Ответ: ans
```

## Числа Каталана

Пусть $C_{n}$ &ndash; количество правильных скобочных последовательностей длины $2n$ (с $n$ открывающими скобками и $n$ закрывающими). Пусть $X$ - одна из возможных правильных скобочных последовательностей длины $2n$, тогда эту последовательность $X$ можно разбить на $(A)B$, где $A, B$ - другие возможные правильные скобочные последовательности. Тогда если последовательность $A$ имеет длину $2k$, то последовательность $B$ будет иметь длину $2(n - k - 1)$. В итоге несложно заметить рекуррентное соотношение:

$$
C_{n} = \displaystyle\sum_{i=0}^{n-1} (C_{i}C_{n-i-1})
$$

Реализация динамическим программированием:

```C++
vector<ll> C(n+1, 0);
C[0] = 1;
for (int i = 1; i <= n; i++)
  for (int j = 0; j < i; j++)
    C[i] += C[j] * C[i-j-1];
```
