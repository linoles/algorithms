# Поиск подпоследовательности

## Наибольшая общая подпоследовательность

Наибольшая общая подпоследовательность (НОП, LCS) &ndash; наибольшая возможная (наибольшей длины) последовательность, полученная путём удаления некоторых (возможно нуля или всех) элементов из последовательности $a$, которая также является подпоследовательностью последовательности $b$.

> То есть, если $a = {0, 2, 1, 7, 3}$ и $b = {1, 2, 7, 5, 3, 4}$, то наибольшая общая подпоследовательность последовательностей $a$ и $b$ будет $c = {2, 7, 3}$.

Пусть $LCS(i, j)$ &ndash; длина наибольшей общей подпоследовательности последовательностей $a[1...i]$ и $b[1...j]$. Для нахождения $LCS(i, j)$ можно использовать следующую рекуррентную формулу:

$$
LCS(i, j) = LCS(i-1, j-1) + 1\text{, при } a[i] = b[j] \\
LCS(i, j) = max(LCS(i-1, j), LCS(i, j-1))\text{, при } a[i] \ne b[j]
$$

```C++
vector<vector<int>> LCS(n+1, vector<int>(m+1, 0));
for (int i = 0; i < n; i++)
  for (int j = 0; j < m; j++)
  {
    if (a[i] == b[j]) LCS[i+1][j+1] = LCS[i][j] + 1;
    else LCS[i+1][j+1] = max(LCS[i+1][j], LCS[i][j+1]);
  }
// Ответ: LCS[n][m]
```

## Наибольшая возрастающая подпоследовательность

Наибольшая возрастающая подпоследовательность (НВП, LIS) &ndash; наибольшая возможная (максимальной длины) последовательность $c$, полученная путём удаления некоторых (возможно нуля или всех) элементов данной последовательности, а также в которой для каждого индекса $i$ (кроме последнего) соблюдается $c_{i} < c_{i+1}$. Задача: найти длину НВП данной последовательности $a$.

**Первый способ**: Пусть $LIS(k, l)$ &ndash; последний элемент возрастающей подпоследовательности длины $l$ последовательности $a[1...k]$.

```C++
vector<vector<int>> LIS(n+1, vector<int>(n+1, 1e9));
for (int k = 0; k <= n; k++)
  LIS[k][0] = -1e9;
for (int k = 1; k <= n; k++)
  for (int s = 1; s <= n; s++)
  {
    if (LIS[k-1][s-1] < a[k-1] && a[k-1] < LIS[k-1][s])
      LIS[k][s] = a[k-1];
    else
      LIS[k][s] = LIS[k-1][s];
  }
```

**Второй способ**: Пусть $len_{i}$ &ndash; длина возрастающей подпоследовательности, заканчивающаяся на $a_{i}$. Для каждого $i$ попытаемся найти лучший $j$ (с наибольшим $len_{j}$, но при условии $a_{j} < a_{i}$). Будем продолжать ВП, заканчивающуюся на элементе $j$ и имеющую длину $len_{j}$, элементом $a_{i}$, получая $len_{i} = len_{j}+1$:

```C++
vector<int> len(n, 1);
for (int i = 1; i < n; i++)
  for (int j = 0; j < i; j++)
    if (a[j] < a[i])
      len[i] = max(len[i], len[j] + 1);
// Ответ: *max_element(len.begin(), len.end())
```

Или вариант, с помощью которого можно восстановить всю НВП:

```C++
vector<int> len(n, 1), pred(n, -1);
for (int i = 1; i < n; i++)
  for (int j = 0; j < i; j++)
    if (a[j] < a[i] && len[j] + 1 > len[i]) // Доп. условие: если выгодно
    {
      len[i] = len[j] + 1;
      pred[i] = j; // Сохраняем предшественника
    }
int mx = 0; // Находим длину НВП в len
for (int i = 1; i < n; i++)
  if (len[i] > len[mx])
    mx = i;
vector<int> res;                      // Восстанавливаем ответ
for (int i = mx; i >= 0; i = pred[i]) // Идём по предшественникам последнего элемента НВП
  res.push_back(a[i]);
reverse(res.begin(), res.end()); // Переворачиваем, т.к. шли с максимума вниз
// Ответ: подпоследовательность res
```

**Третий способ** ($O(n * log_{2}m)$): Пусть $e_{i}$ &ndash; минимальный $a_{x}$, которым может заканчиваться возрастающая подпоследовательность длины $i$ после обработки элемента $a_{k}$, а также при условии, что $e_{0} = -\infty$ и $e_{z} = \infty$ ($z > 0$). Теперь на каждом шаге ($k$) мы можем находить бинарным поиском такое $j$, что $e_{j-1} \le a_{k+1} < e_{j}$, и после присвоить $e_{j} = a_{k+1}$.

Самое простое решение с использованием STL:

```C++
vector<int> e;
for (int x : a)
{
  auto it = lower_bound(e.begin(), e.end(), x);
  if (it == e.end()) e.push_back(x);
  else *it = x;
}
// Ответ: e.size()
// Тут будет сложнее восстановить НВП, т.к. придётся хранить ещё несколько доп. массивов
```
